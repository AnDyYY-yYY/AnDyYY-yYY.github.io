# Clair Obscur: Expedition 33 — Rooftop Runner Prototype

This repository now includes a lightweight browser runner where Santa sprints across snowy rooftops. Open `index.html` directly in a browser or serve the project locally to try it out.

## Playing

1. Open `index.html` in your browser (or run `python -m http.server` from the repo root and visit `http://localhost:8000`).
2. Press **Space/Up/W** or tap to jump.
3. Hold **Down/S** or press on the lower part of the canvas to duck.
4. Avoid chimneys, antennas, and ice patches while your score and distance climb. Your best score persists in `localStorage`.
